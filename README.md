# Portofolio — Nur Berlian Putri

Website portofolio pribadi yang menampilkan profil, pengalaman, dan proyek selama
menjadi mahasiswa Program Studi Teknik Komputer, Universitas Negeri Makassar (UNM).
Dibangun sebagai bagian dari pembelajaran HTML & CSS di kelas **TEKOM D**.

## Struktur Halaman

| File                | Deskripsi                                                                  |
|---------------------|----------------------------------------------------------------------------|
| `index.html`        | Halaman utama — perkenalan singkat, ringkasan skill, dan fakta singkat.    |
| `tentang.html`      | Profil lengkap, cerita singkat, dan progres skill.                         |
| `pengalaman.html`   | Daftar proyek selama kuliah (`#proyek`) dan kegiatan semasa SMA (`#sma`). n|
| `kontak.html`       | Formulir kontak dan informasi untuk menghubungi.                           |
| `style.css`         | Berkas CSS eksternal yang dipakai oleh seluruh halaman.                    |
| `foto-profil.jpg`   | Foto profil yang ditampilkan di halaman utama dan "Tentang Saya".          |

## Fitur

- Navigasi responsif dengan menu dropdown (Pengalaman → Proyek / Semasa SMA)
- Tampilan *hero section* dengan background bertingkat
- Kartu proyek (grid 3 kolom) untuk menampilkan pengalaman kuliah
- Formulir kontak sederhana (demo, belum terhubung ke backend)
- Desain gelap (dark theme) dengan aksen warna amber

## Catatan

Proyek ini merupakan dokumentasi pembelajaran Git dan pengembangan web statis
di kelas TEKOM D 2025, Universitas Negeri Makassar.
